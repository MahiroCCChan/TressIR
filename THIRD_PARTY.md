# Third-party material policy

The public release candidate contains no third-party character model, texture pack, or proprietary game asset.

The private pre-release Sword06C research workspace contains materials that are **not** redistributable under the TressIR code license. Those materials are intentionally excluded from this repository.

Contributors must only add images, meshes, textures, or other media that they are legally allowed to redistribute, and should document the source and license in the same pull request.
