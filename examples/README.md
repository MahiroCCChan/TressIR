# Portable examples

The public release currently includes profile-level fixtures only. They are intended to exercise the deterministic geometry backend without requiring a proprietary character model or reference image.

`profiles/` contains:

- connected sheets with 2, 3, and 5 named tips/features;
- a synthetic depth-field-style sheet fixture;
- a legacy clump compatibility fixture.

A public image/structure example will be added only after its media redistribution rights are confirmed. Users can already run the trace/structure workflow with their own images.
